# Polices

Servies localement pour que la démo ne dépende d'aucun CDN.

| Police | Source | Licence |
|---|---|---|
| Clash Display | [Fontshare](https://www.fontshare.com/fonts/clash-display) (Indian Type Foundry) | ITF Free Font License — usage libre, incorporation autorisée |
| Satoshi | [Fontshare](https://www.fontshare.com/fonts/satoshi) (Indian Type Foundry) | ITF Free Font License — usage libre, incorporation autorisée |

Sous-ensembles `woff2` uniquement (latin). En cas d'absence de ces fichiers,
les `@font-face` de `app/index.html` retombent sur les polices système.
